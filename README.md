## 💹 Featured Projects

### [Quantfund Engine](https://github.com/felipebns/quantfund_engine)
End-to-end ML backtesting engine for daily, long-only portfolio research: feature engineering → walk-forward validation (Information Coefficient) → LSTM model training → multi-strategy backtesting with transaction costs/slippage → allocation (top-K, probability weighting) → equity curve & performance reporting.

### [Macro Engine](https://github.com/felipebns/macro_engine)
LLM-powered tool that maps macroeconomic scenarios (FX, rates, inflation) to sector and stock-level impact, grounding rationale in transmission mechanisms and running a self-critique pass for consistency. Ships as an interactive Streamlit app with structured JSON + markdown output.

### [Earning Calls Report](https://github.com/felipebns/earning_calls_report)
Automated earnings-call analysis pipeline: extracts management tone, guidance changes, quality of analyst Q&A, red flags, and a surprise score from transcripts, comparing the current quarter against the prior one. Outputs a structured JSON analysis plus an executive markdown report.
